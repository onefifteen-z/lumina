Inside the app

Built for the way you already work

The layout mirrors the real desktop shell: icon rail, article list, content toolbar, and the same light palette as the product (amber primary on soft gray rails). Point the app at a vault that lives in a Box folder, a SharePoint-synced library, or a Git checkout — your team’s Markdown stays where IT already governs versions and access.

Read & write with live preview

The article browser splits the same way as Lumina: file list on the left, toolbar with back/forward and edit controls on top, and the reading surface below — Markdown, wikilinks, and tags exactly like your Obsidian vault on disk.

Obsidian-ready vaults

Open your existing folders — frontmatter, wikilinks, embeds, and tags travel with you. Host that folder in Box, sync it from SharePoint, or track it in Git; Lumina is just the editor over the files on disk.

↺

Box, SharePoint, or Git for teams

There is no separate Lumina cloud for your wiki. Use Box or SharePoint for shared folders and enterprise controls, or Git for branches, diffs, and code-style review — then everyone opens the same vault in Lumina.

✦

Inline AI assist

Summarize, expand, or refine any selection without leaving the editor flow.

⌁

Multi-vault memory

Switch projects instantly; each vault keeps its own history, theme, and chat sessions.

◆

Readers built in

PDF and HTML live beside your notes — research stays inside one window.

◎

Light & dark moods

Amber accents and paper textures in both themes, plus respect for system appearance.

⚙

Optional observability

Wire OpenTelemetry to your own Phoenix server when you want traces — off by default.

Privacy is the default setting

No forced cloud sync. No hidden analytics pipeline. Your API keys stay in the OS keychain, your Markdown stays on disk, and Lumina only phones home to the LLM endpoint you trust — because you typed the URL yourself.

If you collaborate, keep the vault in Box, SharePoint, or Git — Lumina does not host a parallel wiki cloud; it reads and writes the folder those tools already version for your team.

Developers & curious humans

Clone, install, run

git clone https://github.com/McK-Playground/prj-lumina.git
cd prj-lumina
npm install
npm run dev

End users: use the Box download above. Developers: first launch picks a vault folder; add your model under Settings. Full docs in the README.

macOS (private beta). The distributed app is not Apple-notarized yet. After installing Lumina.app to /Applications, run once in Terminal: 

xattr -dr com.apple.quarantine /Applications/Lumina.app

Then open Lumina from Finder.
