# Project Notes

## CRITICAL: No `cd` in bash commands

- NEVER use `cd` in executeBash commands. It is not supported and will fail every time.
- BAD: `cd /Users/joeblock/kiro-test && npx vitest run`
- GOOD: `npx vitest run` (commands run from workspace root by default)
- If you need a different working directory, use the `cwd` parameter on the tool call.

## Running Tests

- Use `npx vitest run` directly — no `cd`, no `&&` chaining.
